# Gate 6 — COMPOSE: same broadcasts, different receiver state

Development receipt, not confirmatory evidence.

## Why this gate

The differentiation branch (Oja -> Sanger -> AMUSE) is valid, but it is not the main hypothesis that motivated the backwards repo.

The main hypothesis is:

```text
broadcast
   -> receiver-relative fit
   -> local nonlinear composition
   -> consequence
   -> consolidation
```

Gate 6 isolates only the middle verb:

> **Can the same fixed network compute different conjunctions from the same broadcasts when only fast receiver state changes?**

No learning, utility, mass, geometry, source separation, or weight update is allowed.

## World

Two independent broadcasts carry two real values each:

```text
A = [a0, a1]
B = [b0, b1]
```

Every exact `(A,B)` pair is presented twice, once in each receiver state.

State 0 asks for the like-with-like relation:

```text
C = a0*b0 + a1*b1
```

State pi asks for the crossed relation:

```text
D = a0*b1 + a1*b0
```

So this is literal rebinding of the same incoming content.

## Fixed local nonlinear subunits

There are four fixed conjunction subunits. The nonlinearity is written as a square-law identity:

```text
q(a,b) = ((a+b)^2 - a^2 - b^2)/2 = a*b
```

The receiver therefore always has the same four potential relations:

```text
q00 = a0*b0
q01 = a0*b1
q10 = a1*b0
q11 = a1*b1
```

Nothing about those slow weights or the topology changes.

A single fast circular receiver state `theta` controls which family is effective:

```text
theta = 0   -> q00 + q11
theta = pi  -> q01 + q10
```

## Result

Twelve-seed held-out ledger:

| arm | NMSE |
|---|---:|
| **receiver phase/state composer** | **0.0000** |
| **ordinary scalar mode switch** | **0.0000** |
| fixed bilinear readout, no state | `0.4978 ± 0.0178` |
| receiver state but linear/no conjunction | `1.0024 ± 0.0016` |
| shuffled receiver state | `0.9866 ± 0.0437` |
| frozen receiver state | `0.9957 ± 0.0356` |

The phase-state composer and an ordinary scalar mode switch are identical to machine precision.

That is not an embarrassment. It is the main attacker.

## Reversibility

For each unseen exact broadcast pair, evaluate:

```text
theta=0 -> theta=pi -> theta=0
```

The mean change in output when rebinding is:

```text
1.2686
```

and returning to the original receiver state returns to the original computation with maximum numerical difference:

```text
0.0
```

So the same slow structure can reversibly realize two different conjunctions.

## What actually earned a job

Two ingredients are load-bearing in this toy.

### Fast state

Remove or scramble the receiver state and the system cannot know which relation is currently requested.

### Local nonlinearity

Give the model the same state-dependent gates but only linear combinations of the raw broadcasts and it cannot represent the multiplicative conjunctions (`NMSE ~ 1`).

So the tested primitive is:

```text
FAST RECEIVER STATE
chooses which potential relation is effective now

+

LOCAL NONLINEARITY
turns co-present inputs into a conjunction
```

## What phase did NOT earn

Phase did **not** beat an ordinary scalar switch.

In this gate, phase is simply a circular encoding of a fast mode variable. Therefore the surviving claim is deliberately modest:

> **Fast receiver state can reversibly select different nonlinear compositions in fixed slow structure. Phase is one possible state coordinate, not a new source of expressive power.**

If later experiments need only an arbitrary scalar mode bit, use the scalar bit.

Phase becomes interesting only if a later gate can obtain/use the state locally from ongoing dynamics, timing, or receiver-relative arrival without being handed an explicit mode label.

## What this does not show

- phase is better than ordinary gating;
- a biological dendrite implements these exact square-law subunits;
- conjunctions are semantic concepts;
- receiver state will self-organize;
- useful conjunctions will be selected without labels;
- growth can consolidate a transient composition;
- composition scales beyond this tiny known-answer world.

## Next

Do **not** add growth yet.

The next main-line question is whether the receiver state can be generated by the interaction itself rather than supplied as an explicit mode variable.

One clean attack would keep the same fixed conjunction bank but replace the externally set `theta in {0,pi}` with a local dynamical receiver whose state is perturbed by preceding context. Then ask whether the same broadcast is composed differently because of **what the receiver was already doing**, not because the experiment handed it a mode bit.

Only if that survives should utility enter:

```text
transient composition
      -> consequence/error
      -> which composition mattered?
```

and only after that should mass/geometry be allowed to consolidate it.
